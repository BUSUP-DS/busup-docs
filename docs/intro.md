# Welcome to BUSUP-DS

The **BUSUP Design System** is our single source of truth for building consistent, high-quality corporate mobility experiences. This system bridges the gap between design vision and production-ready code.

## 🛠 How we build

This documentation is **AI-driven** and follows a modern design-to-code pipeline:

1. **Figma** as our creative canvas.
2. **Claude + MCP** to extract high-fidelity tokens.
3. **Docusaurus** to host and maintain this living documentation.

<br />


## 🚀 Getting Started

If you are a **Developer**, check our [Design Tokens](./design-tokens/colors) to start using our variables.

If you are a **Designer**, ensure you are using the latest version of our [Figma Library](https://www.figma.com/design/D2qZyPt7FCRYFTOeW99LVy/APP?node-id=8744-9409&t=38URR2vlwSJ60yaF-4).
