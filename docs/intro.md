# 🚌 Welcome to BUSUP-DS

The **BUSUP Design System** is our single source of truth for building consistent, high-quality corporate mobility experiences. Created by a **Product Designer**, this system bridges the gap between design vision and production-ready code.

---

## 🎯 Our Principles

- **Efficiency:** Don't reinvent the wheel. Use existing components to move faster.
- **Consistency:** Every button, font, and spacing follows a strict logic.
- **Accessibility:** Our components are built to be inclusive and readable for everyone.

## 🛠️ How we build
This documentation is **AI-driven**. We use a modern pipeline:
1. **Figma** as our canvas.
2. **Claude + MCP** to extract tokens.
3. **Docusaurus** to host our living documentation.

---

## 🚀 Getting Started

If you are a **Developer**, check our [Design Tokens](./design-tokens/colors) to start using our variables.
If you are a **Designer**, ensure you are using the latest version of our [Figma Library](URL-DO-SEU-FIGMA).
