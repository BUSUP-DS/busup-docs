# App Driver

App Driver is the mobile application used by BUSUP drivers to manage their routes, passengers, and service status. It shares Foundation tokens and several components with App User, but is optimised for **in-vehicle use** — large tap targets, high contrast, and minimal interaction complexity.

---

## Status

:::caution Work in progress
The App Driver component library is currently being documented. Components will be added progressively.
:::

---

## What to expect

App Driver components will cover patterns for driver-specific workflows:

- **Route & Trip controls** — start/end trip, passenger check-in management
- **Status indicators** — large, glanceable feedback signs optimised for quick reads
- **Notifications** — driver alerts, route changes, passenger boarding updates
- **Shared components** — Navigation Bar, Toast, Badge, Feedback Signs adapted for driver context
