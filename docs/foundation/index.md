# Foundation

Foundation is the shared base of the BUSUP Design System. It defines the visual language that all products — App User, Dashboard, and App Driver — inherit and build upon.

It includes the design decisions that must remain consistent across every surface: colour tokens, spacing scale, typography system, and interaction principles.

---

## What's in Foundation

| Section | What it covers |
|:---|:---|
| **Colours** | BUSUP's full colour token system — Primary, Neutral, Semantic (Alert, Danger, Info, Success) |
| **Spacing** | The spacing scale used for padding, margin, and layout gaps |
| **Typography** | Typeface, weight scale, size scale, and line-height rules |
| **Principles** | The design values that guide decisions across all products |

---

:::info
Foundation tokens are **product-agnostic**. When a product-specific component deviates from a Foundation token, that deviation is documented in the product's own section — not here.
:::
