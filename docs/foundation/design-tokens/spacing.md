# Spacing

Our spacing system ensures consistency across all components and layouts. We use a **4px base grid**.

| Token | Value | Visual |
| :--- | :--- | :--- |
| `spacing-2xs` | 2px | ![2px](https://via.placeholder.com/2/00bf6f/00bf6f) |
| `spacing-xs` | 4px | ![4px](https://via.placeholder.com/4/00bf6f/00bf6f) |
| `spacing-sm` | 8px | ![8px](https://via.placeholder.com/8/00bf6f/00bf6f) |
| `spacing-md` | 12px | ![12px](https://via.placeholder.com/12/00bf6f/00bf6f) |
| `spacing-lg` | 16px | ![16px](https://via.placeholder.com/16/00bf6f/00bf6f) |
| `spacing-xl` | 20px | ![20px](https://via.placeholder.com/20/00bf6f/00bf6f) |
| `spacing-2xl` | 24px | ![24px](https://via.placeholder.com/24/00bf6f/00bf6f) |
| `spacing-3xl` | 28px | ![28px](https://via.placeholder.com/28/00bf6f/00bf6f) |

:::info Implementation
Developers should use the CSS variables (e.g., `padding: var(--spacing-md);`) instead of hardcoded pixel values.
:::
