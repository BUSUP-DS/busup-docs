# Buttons

Buttons allow users to take actions and make choices. In the BUSUP ecosystem, we follow a strict hierarchy to ensure clarity.

### Primary Button
The main action on the page. Use only **one** per context.
* **Color:** `color.primary.300` (#00A355)
* **Usage:** Confirming, saving, or submitting.

### Secondary Button
Complements the primary action or stands alone for alternative paths.
* **Color:** `color.neutral.100` (#F8F9FA)
* **Usage:** "Next", "Clear all", "Back".

### Danger State (Critical)
When the primary action is to **delete or cancel** something irreversible.
* **Color:** `color.secondary.300` (#E05243)
* **Usage:** "Yes, Delete", "Cancel Reservation".
