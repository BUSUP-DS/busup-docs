# Dashboard

Dashboard is the web-based back-office product for BUSUP operators and administrators. It shares Foundation tokens with all other products but has its own set of components optimised for **dense data display**, complex forms, and management workflows on desktop and tablet.

---

## Status

:::caution Work in progress
The Dashboard component library is currently being documented. Components will be added progressively.
:::

---

## What to expect

Dashboard components will cover patterns specific to data-heavy interfaces:

- **Data Tables** — sorting, filtering, pagination, inline actions
- **Forms** — complex multi-step forms, field validation patterns
- **Charts & Metrics** — KPI cards, usage graphs, occupancy indicators
- **Modals & Drawers** — confirmation dialogs, side panels for detail views
- **Shared components** — Badge, Toast, Feedback Signs adapted for desktop contexts
