# App User

App User is the passenger-facing mobile application. It is the primary product of the BUSUP Design System and the most complete in terms of documented components.

It is built for **iOS and Android**, follows native platform conventions where appropriate (particularly iOS micro-interactions), and prioritises clarity and speed for users navigating their daily commute.

---

## Component library

All components documented in this section are specific to or first defined for App User. Components that are shared with other products may have product-specific variants documented in each product's section.

| Category | Components |
|:---|:---|
| **Navigation** | Navigation Bar, Side Menu, Tabs |
| **Feedback** | Toast, Feedback Signs, Feedback Modals, Notification |
| **Input & Controls** | Buttons, Text Input, Form Controls, Code Input, Segmented Control |
| **Data display** | Cards, Ticket, Progress Bar, Badge, Avatar |

---

:::info
App User adopts iOS native micro-interactions in certain components (e.g. Navigation Bar). This is intentional — do not override animations the system already provides.
:::
