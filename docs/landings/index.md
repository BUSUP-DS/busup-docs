# Landings

Landings is the BUSUP web application — the public-facing product where users search routes, manage their bookings, and log in to their account. It is a desktop-first responsive web experience.

---

## Unique components

These components exist only in Landings and are documented in this section.

| Component | Description |
|:---|:---|
| [Navigation Header](/busup-docs/docs/landings/navigation-header) | Desktop top bar — logo, nav links, language selector, user profile |
| [Search Bar](/busup-docs/docs/landings/search-bar) | Route search form — Origin, Destination, Date, Time + Search button |
| [Title](/busup-docs/docs/landings/title) | Section title typography scale — 6 size/weight variants |
| [Calendar Modal](/busup-docs/docs/landings/calendar-modal) | Date picker overlay — opens from the Date field in the Search Bar |
